# Barcode Keyboard 2

自用 Android 英文輸入法，按下字母立即輸出，不提供拼音、筆畫、速成、九宮格或候選字列。鍵盤高度固定為 340dp，並保留內嵌條碼掃描與商品資料工具。

## 功能

- **英文直輸**：QWERTY 鍵盤，按下字母立即寫入游標位置，不載入中文詞庫、不計算或顯示候選。支援 Shift 大寫、數字／符號鍵盤、空格、刪除、長按連續刪除及 Enter。
- **鍵盤內條碼掃描**：掃描畫面限制在與鍵盤相同的 IME 視窗，不開全螢幕掃描頁；條碼解碼不成功時會嘗試 OCR 讀取條碼下方數字。
- **掃描後 Enter**：掃描成功後回填並觸發目前輸入欄位的 Enter／搜尋／完成動作；文字 OCR 僅回填文字。
- **重掃替換**：若上一次掃描結果仍緊鄰游標之前，再掃描會取代前一碼，不刪除其後其他輸入內容。
- **商品 XLSX 匯入**：從系統文件選擇器讀取商品名稱、條碼及第二條碼欄位；原始 XLSX 不會複製到 App 或打包進 APK。商品名稱與條碼對照僅儲存在裝置本機。
- **快捷工具**：可自行使用本機常用語、表情、剪貼簿、游標控制及觸感／按鍵聲開關；這些不是輸入法切換模式。
- **隱私**：鍵盤輸入、剪貼簿記錄、常用語及商品目錄均在本機，不設輸入內容上傳或雲端同步。

## 安裝及設定

1. 安裝 `BarcodeKeyboard2-v1.4.1-debug.apk`。
2. 到 Android「設定 → 系統 → 鍵盤／語言與輸入法 → 螢幕鍵盤」啟用 **Barcode Keyboard**。
3. 在文字欄位切換至 Barcode Keyboard；輸入字母即直接出字。
4. 首次掃描時授予相機權限；匯入商品時，從系統文件選擇器挑選 XLSX。

若條碼含前置零，請將 Excel 條碼欄設定為文字格式，避免試算表先移除前置零。

## 建置

需要 JDK 17+、Android SDK Platform 35 及 Gradle 8.7：

```sh
./gradlew assembleDebug
```

APK 位置：`app/build/outputs/apk/debug/app-debug.apk`。自用版本使用 Android debug 簽章；以不同簽章建置的 APK 不能直接覆蓋安裝。
