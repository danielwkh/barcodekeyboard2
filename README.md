# Barcode Keyboard 2

自用 Android 輸入法，加入鍵盤內 QR／Barcode／文字掃描、中文輸入及本機商品資料匯入。

## 功能

- **鍵盤內掃描**：IME 視窗固定為 340dp；相機預覽只顯示在鍵盤面板內，不使用全螢幕掃描頁。
- **條碼數字備援**：若條碼圖案因墨水太濃等原因無法直接解碼，會自動使用中文 OCR 辨識畫面中的獨立數字列，優先讀取印在條碼下方的數字；短數字價錢不會作為條碼候選。
- **掃碼後自動 Enter**：條碼回填後會自動觸發目前輸入欄的 Enter 動作；若欄位設定了搜尋／完成等動作，就執行該動作，否則輸入換行。文字 OCR 模式只回填文字，不自動提交。
- **連續掃描**：同一輸入欄再次掃碼時，若上一個掃描結果仍緊鄰游標之前，會先替換舊結果；若使用者已在後方編輯文字，則不會刪除不相干內容。
- **輸入模式**：English、拼音、筆畫、速成；每種模式都有 Enter 鍵及常用候選。所有刪除鍵支援長按連續快速刪除。
- **商品 XLSX 匯入**：依提供的範本讀取第一張「商品」工作表中的「名稱」、「條碼」、「第二條碼」欄位，主條碼及第二條碼都會對應同一商品名稱；第二張「店鋪庫位」工作表忽略。也支援一般 `Barcode`／`Product Name` 欄名。
- **本機資料**：原始 XLSX 僅在選取後即時讀取，不複製到 App 資料夾或打包進 APK；匯入後只有條碼與商品名稱對照儲存在裝置本機。掃描畫面及輸入內容不會由本 App 傳送到伺服器。

## 安裝及設定

1. 安裝 `BarcodeKeyboard2-v1.3.2-debug.apk`。
2. 到 Android「設定 → 系統 → 鍵盤／語言與輸入法 → 螢幕鍵盤」啟用 **Barcode Keyboard**。
3. 在文字欄位切換至 Barcode Keyboard。
4. 首次使用掃描時授予相機權限；匯入商品時，從系統檔案選擇器挑選 XLSX。

若條碼含前置零，請將 Excel 條碼欄設為文字格式，避免試算表先行移除前置零。

## 字典授權與建置

拼音、筆畫及倉頡字典來源與授權檔案列於 `app/src/main/assets/dictionaries/NOTICE.txt`。建置需要 JDK 17+、Android SDK Platform 35 及 Gradle 8.7：

```sh
./gradlew assembleDebug
```

APK 位置：`app/build/outputs/apk/debug/app-debug.apk`。此自用版本使用 Android debug 簽章；以不同簽章建置的 APK 不能直接覆蓋安裝。
