# Barcode Keyboard 2

自用 Android 輸入法，參考常用中文鍵盤的精簡候選列與工具列，並加入鍵盤內 QR／Barcode／文字掃描，以及本機商品資料匯入。

## 功能

- **掃描器與鍵盤同尺寸**：IME 視窗高度固定為 340dp；相機預覽只替換鍵盤面板內容，不啟動全螢幕掃描 Activity。支援條碼／QR 掃描與中文文字辨識；掃描後切回鍵盤並輸入結果。
- **四種輸入模式**：English、拼音、筆畫、速成。每種模式都有明確的「↵ 換行」鍵。輸入時顯示常用候選：英文顯示常用詞建議，拼音、筆畫及速成顯示本機字典候選並優先排列常用字。
- **筆畫鍵盤版面**：按參考圖採用深色大按鍵格狀排列，包含橫「一」、豎「丨」、撇「丿」、點「丶」、折「乙」，並提供刪除、清除、數字符號、空白、切換輸入法與換行鍵。
- 拼音、筆畫與倉頡速成字典內嵌於 APK，候選字在裝置本機查詢。速成依倉頡字碼首尾碼查字。
- **商品 XLSX 匯入**：點鍵盤「商品」或掃描頁「商品資料」，選取本機 `.xlsx`。第一列需有條碼欄及商品名稱欄，例如 `Barcode`、`Product Name`，或 `條碼`、`商品名稱`。掃描頁的輸出按鈕可切換「輸出條碼／輸出品名」；若商品表找不到該條碼，會退回輸出條碼。
- **本機資料**：商品表儲存在裝置本機，不會上傳到本專案伺服器。掃描相機畫面和輸入內容不會由本 App 傳送到伺服器。
- **連續掃描**：同一輸入欄連續掃描時，若上一個掃描結果仍在游標前方，會先刪除舊結果再輸入新條碼；若使用者已在其後編輯文字，則不會刪除不相干內容。
- **長按刪除**：所有鍵盤模式的刪除鍵均支援長按連續快速刪除。
- **連續掃描**：同一輸入欄連續掃描時，若上一個掃描結果仍在游標前方，會先刪除舊結果再輸入新條碼；若使用者已在其後編輯文字，則不會刪除不相干內容。
- **長按刪除**：所有鍵盤模式的刪除鍵均支援長按連續快速刪除。

## 安裝及設定

1. 安裝 `BarcodeKeyboard2-v1.3.0-debug.apk`。
2. 到 Android「設定 → 系統 → 鍵盤／語言與輸入法 → 螢幕鍵盤」啟用 **Barcode Keyboard**。
3. 在文字欄位切換至 Barcode Keyboard。
4. 首次使用掃描時授予相機權限；匯入商品時，從系統檔案選擇器挑選 XLSX。

## XLSX 欄位格式

依照提供的 `西環_20261015_0044.xlsx` 格式，匯入第一張「商品」工作表中的 `名稱`、`條碼`、`第二條碼` 欄位；主條碼和第二條碼都會映射到同一商品名稱。第二張「店鋪庫位」工作表忽略。也支援一般 `Barcode`／`Product Name` 或 `條碼`／`商品名稱` 欄名。原始 XLSX 只在選取後即時讀取，不會複製到 App 資料夾或打包進 APK；僅條碼—商品名稱對照保存在裝置本機。若條碼含前置零，請將 Excel 條碼欄設為文字格式。

## 授權與字典來源

拼音、筆畫及倉頡字典來源與授權檔案列於 `app/src/main/assets/dictionaries/NOTICE.txt`。資料在 APK 內以原始文字字典提供，應用程式於裝置端建立候選索引。字典各自的授權文本也隨專案一併提供。

## 建置

需要 JDK 17+、Android SDK Platform 35 及 Gradle 8.7：

```sh
./gradlew assembleDebug
```

APK 位置：`app/build/outputs/apk/debug/app-debug.apk`。此自用版本使用 Android debug 簽章；以不同簽章建置的 APK 不能直接覆蓋安裝。
